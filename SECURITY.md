# Security Policy

## Supported versions

Security fixes are provided for the latest minor release branch.

| Version | Supported |
|---------|-----------|
| latest  | yes       |
| older   | no        |

## Reporting a vulnerability

Please do not create a public issue for security problems.

Preferred channels:

1. GitHub Security Advisory (private report).
2. Email maintainer: `mileo@kmee.com.br`

Include:

- affected version
- reproduction steps
- potential impact
- proposed mitigation (if available)

We will acknowledge the report as soon as possible and coordinate a fix
and disclosure timeline.
