---
title: Notas de débito
description: Incrementá el valor de un DTE existente con un contrato fiscal tipado.
icon: FilePlus
---

```http
POST /v1/emitters/{emitter_id}/documents/notas-debito
```

La nota de débito comparte cliente, ítems, moneda, numeración e idempotencia con
los demás documentos tipados. Siempre requiere `documento_asociado`.

```json
{
  "external_id": "recupero_logistica_77",
  "idempotency_key": "recupero_logistica_77_v1",
  "nota_debito": {
    "establecimiento": "001",
    "punto": "001",
    "moneda": "PYG",
    "motivo_emision": "recupero_costo",
    "documento_asociado": {
      "tipo": "electronico",
      "cdc": "CDC_DE_44_DIGITOS"
    },
    "cliente": {
      "ruc": "80000000-0",
      "razon_social": "Cliente de prueba"
    },
    "items": [
      {
        "descripcion": "Recupero de costo logístico",
        "cantidad": 1,
        "precio_unitario": 45000,
        "tasa": 10
      }
    ]
  }
}
```

El replay con la misma `idempotency_key` devuelve el documento y job originales.
Un payload incompatible no genera una segunda nota.
