---
title: Notas de crédito
description: Ajustá un DTE existente conservando la asociación fiscal.
icon: FileMinus
---

```http
POST /v1/emitters/{emitter_id}/documents/notas-credito
```

La estructura comparte cliente, ítems, moneda e idempotencia con la factura,
pero requiere `documento_asociado`.

```json
{
  "external_id": "devolucion_77",
  "idempotency_key": "devolucion_77_v1",
  "nota_credito": {
    "establecimiento": "001",
    "punto": "001",
    "moneda": "PYG",
    "motivo_emision": 1,
    "documento_asociado": {
      "tipo": "electronico",
      "cdc": "CDC_DE_44_DIGITOS"
    },
    "cliente": {
      "ruc": "80000000-0",
      "razon_social": "Cliente de prueba"
    },
    "items": [
      {
        "descripcion": "Ajuste de servicio",
        "cantidad": 1,
        "precio_unitario": 50000,
        "tasa": 10
      }
    ]
  }
}
```

Para un DTE electrónico, el CDC asociado debe contener exactamente 44 dígitos.
